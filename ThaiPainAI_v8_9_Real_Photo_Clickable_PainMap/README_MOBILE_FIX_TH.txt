ThaiPain AI v8.6 — HTML Mobile Responsive

เวอร์ชันนี้ยังเป็น HTML/PWA แบบเดิม ไม่ใช่ Node.js

แก้ปัญหาบนมือถือ:
- หน้าเว็บกว้างพอดีหน้าจอ ไม่ล้นซ้าย/ขวา
- รองรับ Android / iPhone
- รองรับ safe-area / notch
- Pain Map เรียง 1 คอลัมน์บนมือถือ
- รูปคนจริงรักษาสัดส่วน ไม่ยืด/ไม่บีบ
- กล้องใช้สัดส่วน 3:4 บนมือถือ
- Slider / ปุ่ม / Card ไม่ล้นจอ
- Modal Camera Permission เต็มความกว้างมือถือ
- รองรับจอ 360–430px
- รองรับ landscape
- ใช้ cache-busting เพื่อช่วยให้มือถือโหลดเวอร์ชันใหม่

อัปเดต GitHub Pages:
1. แตก ZIP
2. อัปโหลดไฟล์ทั้งหมดทับ repository เดิม
3. Commit changes
4. รอ Actions Deploy เป็นสีเขียว
5. ปิดหน้าเดิมบนมือถือแล้วเปิดใหม่
6. หากยังเพี้ยน ให้ Clear site data/cache ของเว็บไซต์แล้วเปิดใหม่
