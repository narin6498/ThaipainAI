ThaiPain AI — Clinical Edition

เวอร์ชันนี้ตัดเมนูสำหรับการนำเสนอ/การแข่งขันออกทั้งหมด:
- ไม่มี Judge Mode 45 sec
- ไม่มี Demo Cases
- ไม่มี Champion Strategy
- ไม่มี Pitch Mode รอบชิง

คงไว้เฉพาะฟังก์ชันใช้งานหลัก:
- Consent & Privacy
- Patient / Practitioner role
- Interactive Pain Map
- AI Body Scan / Camera
- Camera Permission Help + Try Again
- Head-turn / movement proxy
- AI Posture Score (prototype)
- THAI SAFE
- Personalized Thai Care + Practitioner Review
- Treatment Record
- Before / After
- ThaiPain Analytics
- Thai report / PDF / CSV
- PWA install + GitHub Pages

วิธีอัปเดต:
1. แตก ZIP
2. อัปโหลดไฟล์ทั้งหมดทับ repository เดิม
3. Commit changes
4. รอ GitHub Actions Deploy สำเร็จ
5. Refresh หน้าเว็บบนมือถือ
6. หากยังเห็นเวอร์ชันเก่า ให้ล้าง Site data/cache แล้วเปิดใหม่
